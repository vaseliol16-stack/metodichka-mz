# Методичка МЗ

Сайт лежит на GitHub Pages, сервер — Google Apps Script, данные — в Google Таблице.

| Куда | Файлы |
|---|---|
| Репозиторий GitHub | `index.html`, `style.css`, `app.js`, `config.js`, `README.md` |
| Apps Script (не на GitHub!) | `Code.gs`, `Content.gs` |

`Code.gs` и `Content.gs` в репозиторий не кладите: содержание методички должно уходить только вошедшим сотрудникам.

## Установка

1. Создайте новую Google Таблицу. Меню **Расширения → Apps Script**.
2. Замените код в `Code.gs` своим `Code.gs`. Через **＋ → Скрипт** добавьте файл `Content` и вставьте `Content.gs`. Сохраните.
3. Вверху выберите функцию **setup** и нажмите **Выполнить**, разрешите доступ. В журнале выполнения появятся коды доступа подразделений и одноразовый код первого администратора `ADMIN-…`.
4. **Развертывание → Новое развертывание → Веб-приложение**. Выполнять как: **я**. Доступ: **все**. Скопируйте URL, он оканчивается на `/exec`.
5. Вставьте URL в `config.js` в `API_URL` и загрузите файлы сайта в репозиторий. **Settings → Pages**: ветка `main`, папка `/ (root)`.
6. Откройте сайт → **Регистрация** → ваш ник и код `ADMIN-…`. Аккаунт сразу станет admin, код после этого перестаёт работать.

## Роли

| Роль | Что может |
|---|---|
| Пользователь | Читать методичку, отмечать изученное, избранное |
| Старший состав | + видеть сотрудников своего подразделения и их прогресс, принимать заявки, писать объявления подразделению |
| Лидер | + назначать старший состав, блокировать, удалять, выдавать коды сброса пароля, менять код доступа подразделения |
| admin | Всё во всех подразделениях, назначает лидеров, пишет объявления всем |

Роль выдаётся только ниже своей. Второго admin назначают вручную: в таблице, лист «Сотрудники», столбец `role` → `admin`.

## Как правятся разделы

Всё содержание — в `Content.gs`, в начале файла есть шпаргалка по блокам. Раздел с `minRole: 'senior'` увидят только старший состав и выше.

После любых правок в Apps Script: **Развертывание → Управление развертываниями → ✏️ → Версия: «Новая версия» → Развернуть**. Адрес при этом не меняется. Не создавайте новое развертывание при каждом обновлении — старые адреса продолжат работать со старым кодом. Если такие уже есть, отправьте их в архив там же.

## Пароли и безопасность

- Пароль хэшируется в браузере (PBKDF2-SHA256, 600 000 итераций) и в открытом виде в сеть не уходит. На сервере результат ещё раз хэшируется HMAC-SHA256 с личной солью и секретом из свойств скрипта. В таблице только соль и хэш.
- Токены сессий в таблице тоже хранятся хэшем. Без «Запомнить меня» сессия живёт 12 часов, с ним — 30 дней.
- После 5 неверных попыток вход по этому нику закрывается на 15 минут.
- Забытый пароль: лидер выдаёт код сброса (действует 24 часа), сотрудник вводит его по ссылке «Забыли пароль?».
- Не открывайте таблицу «всем, у кого есть ссылка». Все действия руководства пишутся на лист «Журнал».
